- ctrl + shift + P : 명령 팔레트
- Spring Initalizr : Create a Gradle Project

- Group : com.aloha
- Artifact : jpa
- Packaging : War
- Java : 17 (23)

2. 의존성 추가
- Spring Web
- SpringBoot DevTools
- Lombok
- Spring Data JPA
- MySQL Driver

3. 데이터 소스 설정
- application.properties (프로젝트 설정 파일)
```
  # 데이터 소스 - MySQL
  spring.datasource.url=jdbc:mysql://localhost:3306/aloha?serverTimezone=Asia/Seoul&allowPublicKeyRetrieval=true&useSSL=false
  spring.datasource.username=aloha
  spring.datasource.password=123456
  spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

```

4. JPA 설정
- application.properties (프로젝트 설정 파일)
```
  # JPA 
  # ddl-auto 옵션 : create(실행), update(기존유지+변경반영), validate(검증), none(사용안함)
  spring.jpa.hibernate.ddl-auto=update
  spring.jpa.show-sql=true
  spring.jpa.properties.hibernate.format_sql=true
```

5. 엔터티 정의
- @Entity 어노테이션을 클래스에 지정
- @Id 어노테이션을 PK 에 대응할 변수에 지정
- no 번호 자동증가 옵션 :  @GeneratedValue(strategy = GenerationType.IDENTITY)
```
  @Entity
  public class Orders {
    @Id
    private Integer no;
  }
```

5. Repository 정의
* JpaRepository<엔터티, PK> 인터페이스를 상속받아서 정의
```
  public interface OrderRepository extends JpaRepository<Orders, Integer> { }
```

6. Service 정의
* 사용할 Repository 의존성 주입을 한다.
```
  @Service
  @RequriedArgsContructor
  public class OrderServiceImpl {

    private final OrderRepository orderRepository;

    public List<Orders> list() {
      return orderRepository.findAll();
    }

  }
```

6. Controller 정의
* Serivce 의존성 주입
```
  @RestController
  @RequriedArgsContructor
  public class OrderController {

    private final OrderService;


  }
```
