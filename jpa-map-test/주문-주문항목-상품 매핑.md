# 5. 상품(Product) 엔터티 정의

상품 정보를 저장하는 `Product` 엔터티를 정의합니다.

```java
@Entity
@Getter
@Setter
@NoArgsConstructor
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer no;

    private String name;

    private Integer price;

    private LocalDateTime createdAt;

    private LocalDateTime updatedAt;
}
```

### 상품 테이블

```text
Product
────────────────────────
no          상품PK
name        상품명
price       상품가격
createdAt   등록일시
updatedAt   수정일시
```

# 7. 주문항목(OrderItem) 엔터티 정의

주문에 포함된 **개별 상품**을 저장합니다.

```java
@Entity
@Getter
@Setter
@NoArgsConstructor
public class OrderItem {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer no;

    private Integer price;

    private Integer quantity;

    @ManyToOne
    @JoinColumn(name = "order_no")
    private Orders order;

    @ManyToOne
    @JoinColumn(name = "product_no")
    private Product product;
}
```

### 주문항목 테이블

```text
OrderItem
────────────────────────
no          주문항목PK
order_no    주문FK
product_no  상품FK
price       주문 당시 상품가격
quantity    주문수량
```

# 8. 엔터티 관계

전체적인 관계는 다음과 같습니다.

```text
Product 1 ─────── N OrderItem N ─────── 1 Orders
상품               주문항목                주문
```

즉,

* **상품 : 주문항목 = 1 : N**
* **주문 : 주문항목 = 1 : N**
* **상품 : 주문 = N : M**

이 됩니다.

다만 JPA에서는 `N:M`을 직접 사용하는 것보다 **OrderItem을 중간 엔터티로 두는 방식**을 사용하는 것이 일반적입니다.

```text
Product
   │
   │ 1
   │
   │ N
OrderItem
   │
   │ N
   │
   │ 1
Orders
```

## 14. 주문항목 등록

주문항목을 등록할 때는 **주문 PK와 상품 PK를 이용해서 연관관계를 설정**합니다.

```json
{
    "price": 30000,
    "quantity": 2,
    "order": {
        "no": 1
    },
    "product": {
        "no": 3
    }
}
```

그러면 DB에는 다음과 같이 저장됩니다.

```text
order_item
──────────────────────────────
no    order_no    product_no    price    quantity
1     1            3            30000    2
```

여기서 중요한 점은 **`order_no`와 `product_no`를 직접 필드로 만드는 것이 아니라 `@ManyToOne + @JoinColumn`을 통해 FK를 매핑한다는 것**입니다.

```java
@ManyToOne
@JoinColumn(name = "order_no")
private Orders order;

@ManyToOne
@JoinColumn(name = "product_no")
private Product product;
```

### 핵심 구조

```text
Product
   │
   │  상품 PK
   ▼
OrderItem
   ▲
   │  주문 PK
   │
Orders
```

**상품 하나는 여러 주문항목에 포함될 수 있고, 주문 하나도 여러 주문항목을 가질 수 있습니다.**

따라서 JPA 실습에서는 **`Product → Orders → OrderItem` 순서로 테이블을 만들고, 마지막에 `OrderItem`에서 `@ManyToOne` 관계를 연결**하는 흐름이 가장 이해하기 좋습니다.
